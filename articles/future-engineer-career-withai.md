# 現状整理
エンジニアの働き方はだいたい次のように変わってきた、という整理です（会社によって変更はあります）。
Cursor、Claude Code、Codex、Devinこの辺が登場してから特に下記のように変わってきた気がします。
| | 過去の典型像 | 現在の典型像 |
| --- | --- | --- |
| **仕事の仕方** | 仕様決定・コード記載・テストを点で行う | 仕様決定・コード記載・テストを流れで行う |
| **時間の使い方** | 調査・実装・テストに長時間 | 分解・指示・レビュー・判断に時間が移る |
| **PRの相手** | 人（先輩・レビュアー） | 人 **＋** AI（複数エージェント） |
| **差がつく場所** | 実装速度・言語・フレームワークの習熟 | 要件の言語化・文脈の渡し方・検証と責任・ドメイン知識・AI習熟度（使い方とか） |
